## 📌 Overview

CinemaIQ is a full-stack machine learning application that predicts **box office revenue for South Asian films** — Bollywood, Tollywood, Kollywood, and beyond. It models how budget, cast, director, composer, genre, and release timing jointly drive revenue, and surfaces actionable production strategy insights through an interactive Streamlit dashboard.

---

## ✨ Features

| Tab | What it does |
|-----|--------------|
| **🎯 Prediction Engine** | Input your film's parameters and get pessimistic / base / optimistic revenue forecasts with ROI breakdown |
| **⚔️ Strategy Battle** | Head-to-head comparison of two production configurations — revenue, ROI gauges, and a winner verdict |
| **📊 Market Insights** | Model-derived patterns: optimal release months, genre revenue rankings, top actor & director power indices |

**Throughout all tabs**, an AI Analyst (Groq LLaMA 3.3 70B) delivers concise, data-grounded commentary explaining the *why* behind every number.

**Target variable:** `log1p(revenue)` → inverted back to dollars at inference time.

**Input features used:**

- `log_budget` — production budget (log-scaled)
- `runtime` — film length in minutes
- `vote_average` — IMDb-style audience rating
- `vote_count` — proxy for audience reach
- `release_month` — 1–12
- `star_power` — mean actor power index across cast
- `director_power` — director historical performance index
- `composer_power` — composer historical performance index
- `Genre_*` — multi-hot encoded genre columns

## ⚙️ Setup

### 1. Clone & install

```bash
git clone https://github.com/your-username/cinemaiq.git
cd cinemaiq
pip install -r requirements.txt
```

### 2. Add your Groq API key

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_key_here
```

Get a free key at [console.groq.com](https://console.groq.com).  
The app works without it — AI insight cards are silently skipped if the key is missing.

### 3. Run the pipeline

```bash
# Open and run all cells in order:
jupyter notebook cleaningdata.ipynb
jupyter notebook preprocess.ipynb
jupyter notebook train.ipynb
```

This generates `movie_revenue_model.pkl` and `model_artifacts.pkl`.

### 4. Launch the app

```bash
streamlit run app.py
```

## 🚀 Deploy to Streamlit Cloud

1. Push the repo to GitHub (include `.pkl` files or generate them on deploy)
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**
3. Set the main file to `app.py`
4. Add `GROQ_API_KEY` under **Advanced settings → Secrets**

```toml
# .streamlit/secrets.toml  (for local Streamlit secrets)
GROQ_API_KEY = "your_groq_key_here"
```

## 📈 How Scenario Forecasting Works

Given base inputs, the app generates three scenarios:

| Scenario | Logic |
|----------|-------|
| **Pessimistic** | Rating −0.8, vote count ×0.55, output ×0.78 |
| **Base** | Inputs as-is |
| **Optimistic** | Rating +0.7, vote count ×1.6, output ×1.22 |

ROI is calculated as `(predicted_revenue − budget) / budget × 100`.
